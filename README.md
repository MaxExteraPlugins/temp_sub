## 📖 Описание

Плагин **Temp Sub** для клиентов **exteraGram** и **AyuGram**.

Временная подписка на каналы: автоматический выход из канала через заданный промежуток времени.

---

## 📥 Установка

1. Перейдите во вкладку [**Releases**](https://github.com/MaxExteraPlugins/temp_sub/releases/latest).
2. Скачайте файл плагина `temp_sub_v3.1.0.plugin`.
3. Отправьте файл в Telegram (в «Избранное») или откройте его через проводник в exteraGram / AyuGram.
4. Нажмите на сообщение с плагином и выберите **«Установить плагин»**.

---

## 📋 Совместимость

* **exteraGram:** `>= 12.2.10`
* **AyuGram:** `>= 12.2.10`
* **Plugin SDK:** `>= 1.4.3.3`
